# RAG-система помічник з догляду за сукулентами

## Опис проєкту
Навчальний проєкт з розробки RAG-системи, яка виконує роль помічника з догляду за сукулентами. База знань побудована на основі 1741 допису (відфільтровані за цільовими тегами) з публічного форуму Gardening & Landscaping Stack Exchange.

### Цільова аудиторія:
Початківці, досвідчені власники рослин та флористи, які потребують консультацій щодо догляду, лікування, вибору ґрунту або розмноження сукулентів.

### Типові запити:
Причини погіршення стану рослин, поради з безпечного догляду та розмноження сукулентів, сумісність різних видів у спільних композиціях.

### Критерії гарної відповіді системи:
Ідентифікує конкретну рослину, враховує специфіку сукулентів, містить покрокові безпечні дії, уточнює деталі за потреби, обов'язково посилається на реальні дописи з бази та відхиляє запити поза межами корпусу чи ботаніки.

### Критерії поганої відповіді системи:
Містить галюцинації (вигадані види чи хвороби), пропонує згубні для сукулентів стандартні методи догляду, ігнорує несумісність видів, дає розмиті рекомендації та не містить цитувань джерел.

## Технологічний стек
- **Мова програмування:** Python 3.11+
- **Векторне сховище:** ChromaDB
- **Модель ембедингів:** `all-MiniLM-L6-v2`
- **Модель генерації:** `Llama 3.2 3B`

## Інструкція зі встановлення
**1. Клонування репозиторію:**
```bash
git clone https://github.com/NureLysenkoAnna/rag-project-lysenko.git
cd rag-project-lysenko
```

**2. Налаштування середовища (Windows):**
```bash
python -m venv venv
.\venv\Scripts\activate
```

**3. Встановлення залежностей:**
```bash
pip install beautifulsoup4 chromadb sentence-transformers ollama
```

**4. Запуск LLM (попередньо встановено та запущено Ollama (https://ollama.com/)):**
```bash
ollama run llama3.2:3b
```
